# 机器如何理解人类的情绪 · 在线三感官作品

一个可直接部署到 GitHub Pages 的浏览器独立版本。视觉、听觉、嗅觉模拟读取同一份本轮群体表情分布。当前先提供功能骨架，UI 继续迭代。

## 体验

- **视觉**：原创程序化三维脸、照片四点对齐与区域拼贴、八类表情形变、拖动旋转、全屏。几何是统一风格化脸模，不是重建每个人的真实头形。
- **听觉**：38 个真实管弦采样，配合合成器、弦乐颗粒、反向涌流、FM 微光和漂移回声。保留宇宙声景 v0.4 的音色与情绪映射，点击后播放。
- **嗅觉**：四种虚拟通道的配方、调配、释放、清味与等待；网页不会产生真实气味，也没有连接硬件。
- **参与作品**：摄像头 3 秒采集或选择照片 → 浏览器分析 → 明确加入本轮 → 三感官联动。也可直接用顶部情绪预览体验，无需摄像头与模型。

## 浏览器本地处理

本轮照片、分数和 blob URL 仅保留在当前页面内存；不发送至服务器、不写入数据库，刷新后清空。最多保留最近 20 位，等权汇总。不同浏览器各有自己的本轮作品，不跨访客实时共享。公开地址的访问日志仍由 GitHub 处理。

网页不会自动开启摄像头或声音。摄像头只请求视频，不请求麦克风；离开页面前台时停止摄像头和当前采集，音乐暂停，气味模拟停止。摄像头拒绝授权时可使用照片或情绪预览。

首次点击识别时加载 MediaPipe Face Landmarker 和 ONNX Runtime Web，随后从模型作者的固定 GitHub 提交下载约 16 MB 的 `enet_b0_8_best_afew.onnx`，校验 SHA-256 后在浏览器本机运行。没有向该模型下载地址上传图片。支持的浏览器使用 Worker 与 OffscreenCanvas，将识别移出音频和界面线程；首次识别需下载约 51 MB 的组件与模型。模型加载受网络、设备性能和浏览器 WASM 支持影响；失败会显示错误，可再次尝试，其他预览功能仍可用。

原模型权重没有明确单独的再分发许可，因此本仓库不打包 ONNX 权重，保留原作者来源。依赖与素材清单见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。面部表情分类分数不是对真实内心感受的测量。

## 开发与发布

无 npm 构建步骤，不运行 Python 推理服务。所有静态资源路径支持 GitHub 项目子目录。

```bash
python3 -m http.server 8766
# 浏览器访问 http://127.0.0.1:8766/
node --test tests/*.mjs
```

GitHub Pages 使用本仓库 `codex/site-foundation` 分支的根目录，`.nojekyll` 关闭 Jekyll 处理。发布修改时提交并推送源文件和所需静态资源。仓库仅包括在线版，不包括本机原项目、虚拟环境、私人素材、观众照片或存档。

## 结构

- `index.html` / `static/style.css`：四个功能入口与基础布局。
- `static/app.js` / `session-state.mjs`：浏览器摄像头、照片、内存会话、公共事件。
- `static/browser-inference.mjs`：人脸定位、质量筛选、B0 表情模型的浏览器适配。
- `static/portrait.js` / `procedural-head.mjs`：三维脸、拼贴与表情。
- `static/music*.mjs` / `music.js`：存档版音乐映射、采样与播放。
- `static/scent*.mjs` / `scent.js`：虚拟配方和释放状态机。

## 验证

发布前验证原有音乐、视觉数学与气味逻辑，以及浏览器内会话、模型前处理、程序化几何。浏览器流程覆盖 GitHub 子目录路径、三个板块、八类预览、真实音源、公开测试照片分析与拼贴、刷新清空、桌面及手机布局。112 项 Node 测试通过。Chromium 141 实际通过 38 个音源加载、Worker 内 B0 识别、照片加入与三维拼贴、气味完整周期、四入口与八类联动、摄像头权限拒绝提示、刷新清空以及 1280×900 / 390×844 布局检查。无异常 API/WebSocket/上传请求。

目前的端到端验证使用 Chromium。Safari、手机实体设备、多人长时间参与与真实音箱仍需体验。
