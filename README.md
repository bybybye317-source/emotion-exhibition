# 机器如何理解人类的情绪 · 在线三感官作品

一个可直接部署到 GitHub Pages 的浏览器独立版本。视觉、听觉、嗅觉模拟读取同一份本轮群体表情分布。当前先提供功能骨架，UI 继续迭代。

## 体验

- **视觉**：原创程序化三维脸、照片四点对齐与区域拼贴、八类表情形变、拖动旋转、全屏。几何是统一风格化脸模，不是重建每个人的真实头形。
- **听觉**：38 个真实管弦采样，配合合成器、弦乐颗粒、反向涌流、FM 微光和漂移回声。在宇宙声景基础上，以不同前景乐器、音域、发音与空间强化情绪差异，点击后播放。「悬浮声场」用真实音乐的低频推动薄膜体积、中频牵动褶皱、高频点亮亮边；八类群体表情按完整分布混合形态、材质和色彩，平滑过渡。支持四情绪快捷预览、全屏和单独暂停画面。
- **嗅觉**：四种虚拟通道的配方、调配、释放、清味与等待；网页不会产生真实气味，也没有连接硬件。
- **参与作品**：摄像头 3 秒采集或选择照片 → 浏览器分析 → 明确加入本轮 → 三感官联动。也可直接用顶部情绪预览体验，无需摄像头与模型。

## 浏览器本地处理

本轮照片、分数和 blob URL 仅保留在当前页面内存；不发送至服务器、不写入数据库，刷新后清空。最多保留最近 20 位，等权汇总。不同浏览器各有自己的本轮作品，不跨访客实时共享。公开地址的访问日志仍由 GitHub 处理。

网页不会自动开启摄像头或声音。摄像头只请求视频，不请求麦克风；离开页面前台时停止摄像头和当前采集，音乐暂停，气味模拟停止。摄像头拒绝授权时可使用照片或情绪预览。

首次点击识别时加载 MediaPipe Face Landmarker 和 ONNX Runtime Web，随后从模型作者的固定 GitHub 提交下载约 16 MB 的 `enet_b0_8_best_afew.onnx`，校验 SHA-256 后在浏览器本机运行。没有向该模型下载地址上传图片。支持的浏览器使用 Worker 与 OffscreenCanvas，将识别移出音频和界面线程；首次识别需下载约 51 MB 的组件与模型。模型加载受网络、设备性能和浏览器 WASM 支持影响；失败会显示错误，可再次尝试，其他预览功能仍可用。

原模型权重没有明确单独的再分发许可，因此本仓库不打包 ONNX 权重，保留原作者来源。依赖与素材清单见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。面部表情分类分数不是对真实内心感受的测量。

## 开发与发布

无 npm 构建步骤，不运行 Python 推理服务。所有静态资源路径支持 GitHub 项目子目录。

```bash
python3 -m http.server 8766
# 浏览器访问 http://127.0.0.1:8766/
node --test tests/*.mjs
```

GitHub Pages 使用本仓库 `codex/site-foundation` 分支的根目录，`.nojekyll` 关闭 Jekyll 处理。发布修改时提交并推送源文件和所需静态资源。仓库仅包括在线版，不包括本机原项目、虚拟环境、私人素材、观众照片或存档。

## 结构

- `index.html` / `static/style.css`：四个功能入口与基础布局。
- `static/app.js` / `session-state.mjs`：浏览器摄像头、照片、内存会话、公共事件。
- `static/browser-inference.mjs`：人脸定位、质量筛选、B0 表情模型的浏览器适配。
- `static/portrait.js` / `procedural-head.mjs`：三维脸、拼贴与表情。
- `static/music*.mjs` / `music.js`：音乐映射、采样与播放；`music-analysis.mjs` 测量真实音频，`music-visual*.mjs` 绘制与控制薄膜。
- `static/scent*.mjs` / `scent.js`：虚拟配方和释放状态机。

## 验证

当前 136 项 Node 测试通过，覆盖音乐、视觉数学与气味逻辑，以及浏览器内会话、模型前处理、程序化几何。初次发布的 Chromium 141 验收还覆盖 GitHub 子目录路径、38 个音源加载、Worker 内 B0 识别、测试照片加入与三维拼贴、气味完整周期、四入口与八类联动、摄像头权限拒绝提示、刷新清空以及 1280×900 / 390×844 布局。无异常 API/WebSocket/上传请求。

目前的端到端验证使用 Chromium。Safari、手机实体设备、多人长时间参与与真实音箱仍需体验。

## 听觉可视化 · 2026-10-27

声音与画面共用同一个播放引擎。分析从最终混音的限幅输出旁路读取，左右声道分别测量，避免宽立体声反相抵消；六个声部也分别读取实际振幅。低频为 30–250 Hz，中频为 250–2000 Hz，高频为 2000–12000 Hz。显示采用固定增益，声部条表示实时强度，不再表示预设配比。分析支路不改变输出音色、音量或乐谱。

暂停或静音后，动态相位停止、形变迅速平息；切到其他板块或画面滚出视区时停止绘制。音乐是否播放仍由原有按钮和页面前后台规则决定。「暂停画面」可单独冻结视觉，音乐继续播放。系统的减少动态效果设置会减小变化幅度。WebGL 不可用或中断时提示画面状态，音乐仍能使用。

群体模式读取本轮 `group_scores`，预览模式临时使用所选情绪且不写入记录。没有观众时显示安静的中性薄膜。公开网站的群体仍指当前浏览器的本轮参与者，不跨访客共享。可直接打开 `#music-panel` 进入听觉板块。

Chrome 实播验证实际 RMS/频带与形变联动、静音归零、暂停恢复、八类预览、两位测试参与者的群体分布、全屏、冻结后缩放、隐藏停画、手机布局、减少动态、WebGL 恢复及无 WebGL 时仍可播放。独立音频测试还验证了反相立体声与低/中/高三个频率的分析。真实摄像头采集链路沿用既有版本；听觉的群体输入验收使用浏览器内测试记录。

## 情绪差异 · 2026-10-27

| 情绪 | 声音的前景 | 薄膜形态与色彩 |
| --- | --- | --- |
| 快乐 | 高音小提琴、明亮泛音、通透空间 | 宽展上托、蓝金亮边 |
| 悲伤 | 低大提琴、缓慢长音、暗色长混响 | 纵向垂落、深蓝银灰 |
| 愤怒 | 短发音铜管、粗粝 FM、靠近的低频压力 | 扁厚挤压、密褶与红橙色 |
| 恐惧 | 高音细拍频、间隙、反向采样与漂移 | 不对称蜷曲、紫青色局部颤动 |

保留固定 D/A 基底、缓慢调式色彩、颗粒和反向织体，避免新增明显的和弦循环。四种声音特征由八类情绪的完整分布连续加权，少数情绪仍能参与；视觉也独立混合形态与材质，不按最高分硬切换。已有长音约一秒开始调整前后层级，新特征最迟约 3.5 秒内进入，旧混响自然消退。

听觉板块的四个按钮同步顶部与三维脸预览；选择不会自动播放，也不会写入观众记录。「跟随群体」恢复本轮混合情绪。对比时建议开启声音后，每种情绪停留约 10–15 秒。

工程验证以 Chrome 156 的真实采样引擎各渲染四态 24 秒：无非有限值或削波，四态 RMS 相差约 1.7 dB。去除整体响度后，平均频谱距离从 0.151 增至 0.721，时间包络相关从 0.671 降至 0.106；说明差异来自频谱与时间结构。连续快速切换四态及混合输入也通过，最高 25 个活动声部，暂停后分析归零。以上是信号验证，尚未进行真人试听评价，不能等同情绪辨识率。视觉另检查了相同音频输入下的四态、手机及竖屏全屏，强形变不裁切主体。
