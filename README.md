# 机器如何理解人类的情绪 · 在线三感官作品

一个可直接部署到 GitHub Pages 的浏览器独立版本。视觉、听觉、嗅觉模拟读取同一份本轮群体表情分布。界面采用统一黑色展厅风格，四个入口共用排版、控件和状态样式。

## 体验

- **视觉**：具有连续五官结构的三维雕塑面孔、照片关键点配准与柔边拼贴、八类群体表情混合、拖动查看、缓慢摆动与全屏。底模采用有许可的共用面罩，不是重建每个人的真实头形。
- **听觉**：38 个真实管弦采样，配合合成器、弦乐颗粒、反向涌流、FM 微光和漂移回声。在宇宙声景基础上，以不同前景乐器、音域、发音与空间强化情绪差异，点击后播放。「悬浮声场」用真实音乐的低频推动薄膜体积、中频牵动褶皱、高频点亮亮边；八类群体表情按完整分布混合形态、材质和色彩，平滑过渡。支持四情绪快捷预览、全屏和单独暂停画面。
- **嗅觉**：四种虚拟通道的配方、调配、释放、清味与等待；网页不会产生真实气味，也没有连接硬件。
- **参与作品**：摄像头 3 秒采集或选择照片 → 浏览器分析 → 明确加入本轮 → 三感官联动。也可直接用顶部情绪预览体验，无需摄像头与模型。

## 浏览器本地处理

本轮照片、分数和 blob URL 仅保留在当前页面内存；不发送至服务器、不写入数据库，刷新后清空。最多保留最近 20 位，等权汇总。不同浏览器各有自己的本轮作品，不跨访客实时共享。公开地址的访问日志仍由 GitHub 处理。

网页不会自动开启摄像头或声音。摄像头只请求视频，不请求麦克风；离开页面前台时停止摄像头和当前采集，音乐暂停，气味模拟停止。摄像头拒绝授权时可使用照片或情绪预览。

首次点击识别时加载 MediaPipe Face Landmarker 和 ONNX Runtime Web，随后从模型作者的固定 GitHub 提交下载约 16 MB 的 `enet_b0_8_best_afew.onnx`，校验 SHA-256 后在浏览器本机运行。没有向该模型下载地址上传图片。支持的浏览器使用 Worker 与 OffscreenCanvas，将识别移出音频和界面线程；首次识别需下载约 51 MB 的组件与模型。模型加载受网络、设备性能和浏览器 WASM 支持影响；失败会显示错误，可再次尝试，其他预览功能仍可用。

原模型权重没有明确单独的再分发许可，因此本仓库不打包 ONNX 权重，保留原作者来源。依赖与素材清单见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。面部表情分类分数不是对真实内心感受的测量。

## 开发与发布

无 npm 构建步骤，不运行 Python 推理服务。所有静态资源路径支持 GitHub 项目子目录。

```bash
python3 -m http.server 8766
# 浏览器访问 http://127.0.0.1:8766/
node --test tests/*.mjs
```

GitHub Pages 使用本仓库 `codex/site-foundation` 分支的根目录，`.nojekyll` 关闭 Jekyll 处理。发布修改时提交并推送源文件和所需静态资源。仓库仅包括在线版，不包括本机原项目、虚拟环境、私人素材、观众照片或存档。

## 结构

- `index.html` / `static/style.css`：四个功能入口与基础布局；`static/gallery-theme.css` 提供全站深黑、银灰、香槟色主题与响应式排版。
- `static/app.js` / `session-state.mjs`：浏览器摄像头、照片、内存会话、公共事件。
- `static/browser-inference.mjs`：人脸定位、质量筛选、B0 表情模型的浏览器适配。
- `static/portrait.js` / `portrait-collage.mjs` / `portrait-math.mjs`：三维雕塑、照片配准拼贴与群体表情；`static/models/sculpture-head.glb` 为带形态和法线的脸模。`procedural-head.mjs` 保留为早期程序化模型参考，不再参与网站渲染。
- `static/music*.mjs` / `music.js`：音乐映射、采样与播放；`music-analysis.mjs` 测量真实音频，`music-visual*.mjs` 绘制与控制薄膜。
- `static/scent*.mjs` / `scent.js`：虚拟配方和释放状态机。

## 听觉可视化 · 2026-10-27

声音与画面共用同一个播放引擎。分析从最终混音的限幅输出旁路读取，左右声道分别测量，避免宽立体声反相抵消；六个声部也分别读取实际振幅。低频为 30–250 Hz，中频为 250–2000 Hz，高频为 2000–12000 Hz。显示采用固定增益，声部条表示实时强度，不再表示预设配比。分析支路不改变输出音色、音量或乐谱。

声音强弱同时驱动一个缓慢的呼吸包络：强音打开薄膜的卷曲开口、加大伸展与褶皱，轻声使它逐渐收拢。包络读取最终输出 RMS，使用固定映射，不会把安静段自动放大成高潮。展开时间常数为 0.55 秒，收拢为 2 秒，约 6 秒完成大部分回落；细小频带纹理仍跟随实际声音。

暂停或静音后，漂移相位立即停止，薄膜仍缓慢收拢，至多保留 14 秒的收尾绘制；切到其他板块或画面滚出视区时停止绘制。音乐是否播放仍由原有按钮和页面前后台规则决定。「暂停画面」可立即冻结视觉，音乐继续播放。系统的减少动态效果设置会减小变化幅度。WebGL 不可用或中断时提示画面状态，音乐仍能使用。

群体模式读取本轮 `group_scores`，预览模式临时使用所选情绪且不写入记录。没有观众时显示安静的中性薄膜。公开网站的群体仍指当前浏览器的本轮参与者，不跨访客共享。可直接打开 `#music-panel` 进入听觉板块。

Chrome 实播验证实际 RMS/频带与形变联动、静音归零、暂停恢复、八类预览、两位测试参与者的群体分布、全屏、冻结后缩放、隐藏停画、手机布局、减少动态、WebGL 恢复及无 WebGL 时仍可播放。独立音频测试还验证了反相立体声与低/中/高三个频率的分析。真实摄像头采集链路沿用既有版本；听觉的群体输入验收使用浏览器内测试记录。

## 情绪差异 · 2026-10-27

| 情绪 | 声音的前景 | 薄膜形态与色彩 |
| --- | --- | --- |
| 快乐 | 高音小提琴、明亮泛音、通透空间 | 宽展上托、蓝金亮边 |
| 悲伤 | 低大提琴、缓慢长音、暗色长混响 | 纵向垂落、深蓝银灰 |
| 愤怒 | 短发音铜管、粗粝 FM、靠近的低频压力 | 扁厚挤压、密褶与红橙色 |
| 恐惧 | 高音细拍频、间隙、反向采样与漂移 | 不对称蜷曲、紫青色局部颤动 |

保留固定 D/A 基底、缓慢调式色彩、颗粒和反向织体，避免新增明显的和弦循环。四种声音特征由八类情绪的完整分布连续加权，少数情绪仍能参与；视觉也独立混合形态与材质，不按最高分硬切换。已有长音约一秒开始调整前后层级，新特征最迟约 3.5 秒内进入，旧混响自然消退。

听觉板块的四个按钮同步顶部与三维脸预览；选择不会自动播放，也不会写入观众记录。「跟随群体」恢复本轮混合情绪。对比时建议开启声音后，每种情绪停留约 10–15 秒。

工程验证以 Chrome 156 的真实采样引擎各渲染四态 24 秒：无非有限值或削波，四态 RMS 相差约 1.7 dB。去除整体响度后，平均频谱距离从 0.151 增至 0.721，时间包络相关从 0.671 降至 0.106；说明差异来自频谱与时间结构。连续快速切换四态及混合输入也通过，最高 25 个活动声部，暂停后分析归零。以上是信号验证，尚未进行真人试听评价，不能等同情绪辨识率。视觉另检查了相同音频输入下的四态、手机及竖屏全屏，强形变不裁切主体。

## 群体雕塑肖像 · 2026-10-27

视觉板块由程序化椭球脸换为具有眼窝、鼻翼和连续唇部的雕塑面罩。资产来自作者本人 MIT 示例仓库，固定源版本，经两级细分、坐标统一、法线重建后生成 11.71 MiB GLB，保留 43 个表情形态。来源、修改和重建命令见 [脸模说明](static/models/sculpture-head-README.md)。

八类表情仍读取完整群体分布进行混合，过渡时间常数改为 1.8 秒；约 5.4 秒完成大部分变化。形态法线随表情一同变化，灯光呈现眉眼和嘴部的体积。空白状态使用哑光灰白材质、柔和侧光和细轮廓光。自动旋转改为缓慢左右摆动，手动视角限制在能看清面罩的范围，避免转到没有实体后脑的背面。减少动态设置关闭自动摆动。

观众照片按底模的双眼、鼻尖、六个唇部定位点和完整内唇轮廓配准，分别对齐上唇、口腔和下唇，减少照片牙齿与模型嘴部的错位。旧四点和六点输入仍可使用。轻度调整极端曝光，保留个体色彩差异。原白色硬分割线改为约 10 像素柔边；照片附着在网格顶点上随表情变化。初版按照片数量分配区域；下文的固定碎片版替换了这一行为。此版没有新增个人三维重建，也没有将观众照片上传或持久化。模型加载失败可以在页面内重试，保留本轮参与数据。

本次通过 152 项 Node 测试，并在 Chrome 1440×1100 / 390×844 及 IAB 检查脸模、八类预览、旋转/重置、手机全屏、加载失败重试和清空时的照片异步竞争。用两张公开测试照片实际运行浏览器识别、加入作品、拼贴与群体混合；未开启真人摄像头。无照片上传请求或应用异常。概念参考用于造型、材质和光照方向；交互版本采用开放面罩，未实现参考图中的完整后脑、耳部和颈部雕塑。

## 固定碎片拼脸 · 2026-10-27

打开视觉板块即显示拼好的三维面孔：20 张 AI 生成的虚构成人面孔各贡献一小块，示例素材不计入观众人数，也不产生情绪分数。素材来源与提示词见 [初始素材说明](static/portrait-seeds/README.md)。

真实观众加入时，按固定顺序替换一个区域（首先是眼部）。每位观众只贡献一块，其他人的位置不变；最多保留最近 20 位，第 21 位只替换最早一位的区域。表情仍由真实参与者的完整群体分布混合驱动。清空本轮恢复初始拼脸。刷新也回到示例面孔，当前浏览器的真实照片不会写入网站或公开给其他访客。

初始素材配准后合成为一张 1024 像素纹理，再释放中间图像。观众照片按记录缓存配准结果，新照片加载时保留其他有效片段，淘汰或清空时立即释放对应像素。某张照片失败只回退该区域；初始素材失败时可重试，采集入口仍可使用。

本版 166 项 Node 测试通过，新增真实 LocalSession 的 1/2/20/21 人位置稳定、循环替换、清空归零及失败回退测试。Chrome 使用两张虚构测试照片完成实际识别、加入和群体混合；检查桌面 1440×1100、手机 390×844、单照片失效恢复、清空恢复初始拼脸，以及素材请求失败后的重试。没有照片上传请求或未捕获脚本异常。真人摄像头已尝试启动，但 IAB 未返回视频流，已取消等待；真人采集效果仍待现场验证。

## 拼贴质感细化 · 2026-10-27

保留每张照片的原始色度，继续仅对极端曝光做有限修正；照片在面孔中心的占比从 94% 提升到 98%，让肤色、眉眼和局部纹理差异更清楚。接缝的羽化由 1024 纹理上的 10 像素缩至 4.5 像素，仍保留柔和过渡。固定分区沿共享边做至多约 3.6 像素的静态轻微弯曲，相邻区域使用同一条曲线；五官配准和每位观众占用的位置保持稳定。

没有为片段添加随机色调或厚描边。接缝随三维表情一同运动，边界几何测试验证共享边精确吻合、完整覆盖、无自交及无越界。桌面与手机使用同样素材和视角做前后对比，另以快乐、悲伤及恢复群体预览检查动态拼贴。

## 新观众片段的浮现 · 2026-10-27

摄像头采集成功或点击照片加入后，自动切回视觉板块、恢复「跟随群体」并将大脸滚到视区。新贡献的片段用约 4.8 秒逐渐显现，局部的香槟色柔光在约 6.2 秒内散去；画面上方及右侧标明对应部位。五官和光圈共用脸模的纹理坐标，随表情一起移动。其他照片仍保留自己的固定区域。

过渡时间只在大脸可见、页面位于前台时累计。连续加入会从当前混合外观继续，清空则立即取消过渡、恢复示例拼脸。减少动态效果模式使用约 0.65 秒的短淡入且关闭柔光。失败照片的自动重试不会提前结束其他片段的过渡。

浏览器仅在加入时准备前后两张纹理，每帧由 GPU 混合；不会每帧重新拼合 20 张照片。用于过渡的旧画面在完成或清空时移除。照片仍只在当前页面内存中处理，不上传。

本版通过 181 项 Node 测试。隔离 Chrome 在 1440×1100 和 390×844 下用虚构测试照片走实际分析与加入流程，检查自动导航、群体预览恢复、4.8 秒淡入、6.2 秒退光、片段位置稳定、离开视觉页暂停、返回继续、动画中清空与减少动态模式。另以合成状态验证有效照片与失败照片并存时的重试。没有调用真人摄像头。
